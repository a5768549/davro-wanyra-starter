# Davro Desktop vs. Davro Cloud

Both products share **one Star1Age account** and **one non-expiring pay-as-you-go balance** (`CNY 1 = 1,000 points`), powered by the [Wanyra API](https://api.star1age.cn/en).

| Capability | Davro Desktop ([davro.app](https://davro.app/en/agent)) | Davro Cloud ([cloud.star1age.cn](https://cloud.star1age.cn/en)) |
| --- | --- | --- |
| Platform | Windows 10/11 x64 desktop installer (auto-updates) | Web browser + Android app (iOS planned) |
| Local Disk & Tools | Direct Excel, PDF, PowerPoint, code & shell execution | Isolated cloud workers; optional bridge to paired Davro Desktop |
| Runs While PC Is Off | Requires local PC online | Asynchronous cloud jobs continue even after closing the tab |
| AI Employees & Memory | Single focused desktop agent workspace | Multi-employee workspaces, long-term memory, recurring schedules |
| Secret Handling | Local scoped access + `scope_check` security mode | Dedicated encrypted Vault keeps API keys out of chat logs |
| Multimodal Media | `make_comic` & `make_drama` local deliverables | Quoted cloud generation + cross-device cloud media library |

Read the full comparison on [davro.app/en/guides/davro-desktop-vs-cloud](https://davro.app/en/guides/davro-desktop-vs-cloud).
